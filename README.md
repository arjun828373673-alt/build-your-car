# build-your-car
This project lets users select a car model, pick custom paint jobs, upgrade wheels, and calculate the total build price in real-time.
## Why I Built This

I wanted to challenge myself to create a high-end, luxury-style web app completely from scratch—no heavy frameworks, just clean core web technologies. 
## Features

* ** Multiple Car Models:** Choose between a Sedan, Coupe, or Supercar, each starting with its own base price.
* ** Custom Paint Options:** Real-time color updates with dynamic pricing add-ons (Stock Black, White, Red, Blue).
* ** Wheel Upgrades:** Switch between Stock, Sports, and Racing wheel setups.
* ** Real-time Price Calculator:** Dynamic DOM updates calculate base costs + paint + wheel options as you customize.
* ** Luxury Dark UI:** Styled with gold accents, sleek typography (Cinzel & Montserrat), and a hero image slideshow.
* ** Simulated Checkout Modal:** Interactive confirmation screen when you hit "Purchase Now".
